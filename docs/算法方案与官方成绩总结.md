# 复赛算法方案与官方成绩总结

> 汇总时间：2026-10-01（第二轮官方提交 0.6898 落地后）。
> 覆盖复赛以来全部算法路线与对应官方分数。历史文档中的内部代号在本文一律展开为具体算法描述；文末附代号速查表供交叉检索。

## 一、赛题与评分

- **输入**：每个场景三张对齐图像（可见光 / 红外 / 深度，1920×1080）+ 一句英文描述式查询（如 "The second trash can from left to right"）。
- **输出**：目标物体的归一化 bbox（xyxy）。提交物为 zip 内含 `prediction.json`（qid → 三模态文件名、查询、bbox）。
- **指标**：5690 条官方查询，ACC@IoU≥0.5（单题 0/1 计分）。
- **查询类型分布**（决定策略）：序数类（第几个/最左最右/最大）约 30%，空间描述约 27%，深度/热特征约 8%，其余外观描述约 35%。
- **平台规则**：每天可提交 2 次，取历史最高分。

## 二、总体架构：两阶段"候选池 + 区域选择"

复赛中期起放弃端到端回归，改为两阶段架构，这是全部后续工作的地基：

```
可见光图像 → WeDetect 开放词表检测器 → ≤100 个候选框（按光栅序排列）
          → VLX-Seek-1.5-10B（区域选择式视觉语言模型）在候选中"点名" → 输出选中框
增强配方（0.7188）：LA-3B 独立回归出的框作为第 101 号候选追加进池，仍由 VLX 裁决
```

**选择这个架构的理由**（冻结验证集 2032 行实测）：

- 分数可分解为 **池覆盖率 × 选择正确率**。WeDetect 可见光单模态、100 候选的池覆盖率上限（oracle recall@0.5）= 0.8814。
- 区域选择式模型只"选错"不"框烂"——坐标永远来自检测器，不会输出畸形框；且不弃答（0.3%）。
- 两条铁律：池里没有的答案，选择器训练永远无解（约 10% 错误属池未覆盖）；模型看到的是光栅序候选，检测置信度排名对模型不可见。

### 各发详细说明

**第 1 发 0.5996（V28）**：初赛传承的零样本管线。复赛数据上本地预测 0.29~0.33，官方 0.5996——初赛分数锚点不可平移的最早证据。

**第 2 发 0.661（全强度 LoRA，倒退 3.9pt）**：训练域选对了（RGBT），但数据是广谱撒网、无针对性，且 adapter 以全强度施加。152 例人工审查发现模型塌缩到人/动物候选（训练集 animate 目标仅 0.1%，广谱数据没教会"查询约束 > 视觉显著性"）。关键后续：**同一个 adapter 把 λ 从 1.0 降到 0.3 后，本地 val 反超零样本 +1.5pt**——知识方向对、剂量错。

**0.70（VLX 零样本）**：架构换血后的保底线。本地 val 0.6811 → 官方 0.70（+1.9pt 偏移）。

**0.69（LA-3B 单独）**：验证辅助模型单独的实力。本地 val 0.6324 → 官方 0.69（+5.8pt 偏移，偏移因模型而异）。特性：弃答 15.5%，但出手时 82% 正确——适合当提案器，不适合当裁决者。

**0.7188（λ=0.3 + LA 池追加，当前最高）**：两个改动的乘积：
1. 第一轮 LoRA 降强度到 λ=0.3（val 0.6964）；
2. LA-3B 的框作为第 101 候选池追加（val 0.7215，追加本身贡献 +2.51pt）。

   成因：语义裁决权留在 VLX，LA 只提供位置先验——"LA 知道东西在哪，VLX 知道哪个是题目要的"。官方 0.7188，与 val 几乎零偏移（−0.27pt）。

**0.6898（第二轮定向 LoRA 全强度）**：本地 val 0.7598（历史最高，λ 从 0.3 到 1.0 单调上升），按 47% 迁移率外推预期 0.73~0.75，实际 0.6898——**训练型增益的官方迁移率为负**（val +3.83pt → 官方 −2.90pt）。据此触发预注册止损线（<0.72 不再训练），第三轮迭代取消。

## 四、训练路线细节（三轮，数据配方是核心差异）

### 4.1 第一轮：RGBT 域广谱（官方 0.661）
- 数据：RGBT 域混合构造池 36,604 行，广谱无针对性。
- 超参：LoRA r=32，2 epochs，推理 λ=1.0 全强度。
- 死因三层：剂量过冲（λ0.3 即转正）/ 数据形状没对准病灶（塌缩到显眼物）/ val 通过 ≠ 官方通过。

### 4.2 第二轮尝试：COCO 硬负例（验收未过，从未提交）
- 做法：在第一轮基础上追加 COCO 来源硬负例 8,882 行（显著干扰 6,000 + 序数 2,882），赌"跨域学到的选择能力迁移到 RGBT"。
- 结果：验收闸门 3/5 失败（序数 holdout 0.0879 与基线完全持平、关系类 −1.9pt 退化）。
- 死因：修复后的 COCO 探针证明 COCO 域内确实涨（+4.0/+3.4pt）但 RGBT 域专项指标零移动——**跨域数据教会的是跨域题型，域匹配压倒一切**。8,882 行白烧。

### 4.3 第三轮：病灶定向（官方 0.6898）
- 依据：冻结 val 上 357 个选择错误的解剖——选更小框 39% / 选更大框 27% / 同尺寸错位 28%，**98.7% 发生在无生命目标上**（模型爱选人/动物等显眼物）；另有池未覆盖 208、弃答 52。
- 数据（29,583 行，全部 RGBT 域定向构造）：
  - **抗塌缩硬负例 3,445 行**：同图含行人/动物等生命体干扰、查询目标为无生命物体、且干扰框必须在候选池内——直接教"查询约束 > 视觉显著性"；
  - **序数行 8,673 行**：第 N 个 / 最左最右 / 最大最小类查询；
  - **部件行 2,791 行**：目标部件级查询；
  - 常规行 + 10% 旧数据回放（防灾难遗忘）。
- 超参：LoRA r=32，1 epoch（923 步）。
- 训前三级冒烟（与第一/二轮最大的区别，每个环节先测后烧）：数据静态 QA（干扰物在池内验证、val 污染防护）→ 损失探针（选择 token CE 2.8-3.0 vs 均匀基线 4.6）→ 迷你训练趋势（357 难子集正确率 1.4%→24.4% 单调升，对照组零损伤）。
- 结果：val 0.7598（本地历史最高）但官方 0.6898。训练本身精确命中了病灶，但本地增益不迁移（见第七节）。

## 六、实测否决的方案（附数字，防止重蹈）

| 方案 | 具体做法 | 结果 | 死因 |
|---|---|---|---|
| 多模型多数投票 | 四套官方预测按框一致性投票 | val 0.70 < 纯第三轮 0.76；带否决权变体 0.73 | 弱者拖累强者，任何投票形态都不如最强单模 |
| LA 外挂路由 | LA 框与池重叠度做阈值，决定听 LA 还是听 VLX | +0.2pt（噪声级） | 路由特征分不开"修复"和"打破"两种场景 |
| LA 填补弃答 | VLX 弃答的行改用 LA 的框 | 0/29 正确 | 弃答行恰是两个模型都不会的行 |
| 几何序数修正 | 序数题对池内框按 x 坐标重排取第 N 个 | 序数子集正确率 1.8% vs 模型本身 15.7% | 池框非同类分组，几何排序排错对象 |
| LA 追加叠强 adapter | 第 101 候选技巧叠在第三轮 λ=1.0 上 | 101 个追加框 12.3% 灾难性退化 | 强 adapter 下 LA 框属分布外信号 |
| 外部模型横评 | GLM-4.1V-9B-Thinking：val 0.56（thinking 链在歧义查询死循环不出框，无解析率 14%）；Qwen3-VL-8B 直接回归：val 0.49（输出检测式粗框，三种坐标解释均救不回）；VGNet：val 0.566；GLM-4.6V-Flash 未测（同家族先验 + 域规律，性价比不足） | 全部低于 VLX 系 | **域规律：本域（低光/退化画质 RGBT）上池选择架构对通用回归模型 5 战 5 胜** |

## 七、关键结论（全部有实测数据支撑）

1. **最终有效成绩 0.7188**（平台取历史最高分）：VLX-Seek-1.5-10B + 第一轮 LoRA λ=0.3 + WeDetect 候选池 + LA-3B 第 101 候选追加。
2. **val→官方迁移率分两型**：推理配方改进型 ≈ 47%（val +4.04pt → 官方 +1.88pt，用一次真实提交换来的测量）；**训练型为负**（val +3.83pt → 官方 −2.90pt）。任何本地涨分必须先打折再决策。
3. **adapter 强度与官方分负相关**（4 个官方点）：全强度两次 0.661 / 0.6898，弱强度与零样本 0.7188 / 0.70。最可能的解释是结构性盲区——官方约 30% 序数题而冻结 val 一道都没有（0/2032），强 adapter 恰好在 val 测不到的维度上退化。
4. **多模型结合唯一正收益形态**：让语义理解最强的一方做最终裁决，其他模型只贡献候选/位置先验（池追加 +2.51pt val → 官方 +1.88pt）；外挂路由器几乎必然不如内化仲裁（+0.2pt）。
5. **结构上限**：分数 = 池覆盖率（0.8814）× 选择率（~81%）。破天花板只能靠池升级（红外模态融合、更多提案、检测器微调），本轮比赛窗口内未执行。
