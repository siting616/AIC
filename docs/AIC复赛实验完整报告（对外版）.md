## 一、赛题与评分

- **输入**：每个场景三张对齐图像（可见光 / 红外 / 深度，1920×1080）+ 一句英文描述式查询（如 "The second trash can from left to right"、"The adult woman closest to the camera, leaning down"）。
- **输出**：目标物体的归一化边界框。提交一个包含全部 5690 条查询预测的打包文件。
- **指标**：ACC@IoU≥0.5（单题 0/1 计分）。
- **查询类型分布**（决定策略重心）：序数类（第几个 / 最左最右 / 离相机最近最远）约 **30%**，空间描述约 27%，深度/热特征约 9%，其余外观描述约 34%。
- **平台规则**：每天可提交 2 次，**取历史最高分**（该规则经过一次书面确认与两次实证：低分提交不影响在榜最高分）。

## 三、最终系统架构（0.7188）及其设计逻辑

```
可见光图像 ──► WeDetect 开放词表检测器 ──► ≤100 个候选框（按光栅序编号）
                                                    │
英文查询 ──────────────────────────────► VLX-Seek-1.5-10B（区域选择式视觉
                                          语言模型）：读图与查询，在编号候选
                                          中"点名"一个 ──► 输出该框
辅助框模型（3B grounding 模型）独立出框，作为第 101 号候选加入池中，同样由
VLX 裁决；主模型另施加第一轮 LoRA 微调适配器，推理强度衰减至 0.3 倍。
```

**三个关键设计决策及验证依据：**

1. **两阶段"候选池 + 区域选择"，而非端到端回归框。** 分数可分解为 *池覆盖率 × 选择正确率*（实测：0.8814 × ~82% ≈ 0.72，与官方分吻合）。选择式模型"只可能选错、不可能框烂"（坐标永远来自检测器），且在本赛域（低光/退化画质）上以 5:0 完胜所有通用回归式大模型（GLM-4.1V 本地 0.56 / Qwen3-VL 0.49 / VGNet 0.566，均低于本架构系全部版本）。
2. **微调适配器必须衰减使用（强度 0.3）。** 同一适配器全强度官方 0.661、0.3 倍强度 0.7074——"知识方向对、给药剂量错"（详见第四节）。
3. **多模型融合的唯一正确形态：让语义最强的模型独裁，其他模型只贡献候选。** 辅助框模型单独仅 0.69，但它的框作为候选注入后 +1.14pt——"它知道东西在哪，主模型知道哪个是题目要的"。所有让弱模型参与决策的形态（多数投票 0.70、带否决权投票 0.73、置信度路由 +0.2pt、填补弃答 0/29）全部劣于最强单模。

## 四、微调方向：三轮实验与"本地涨分、官方倒退"的根因

**术语**：LoRA 微调 = 只训练插入主模型的少量适配器权重；推理强度 λ = 对适配器输出的缩放系数，0 = 不用微调（零样本），1.0 = 全强度。

**三轮概要：**

| 轮次 | 训练数据 | 本地验证 | 官方 | 结局 |
|---|---|---|---|---|
| 第一轮 | RGBT 域公开数据广谱混合 36,604 行（无针对性） | λ1.0 过门 / λ0.3 = 0.6964 | λ1.0 → 0.661；λ0.3 → 0.7074 | 全强度倒退；降强度转正，成为最终方案组件 |
| 第二轮 | 第一轮 + COCO 合成硬负例 8,882 行（显著干扰 + 序数） | 验收闸门 3/5 失败 | 未提交 | COCO 域内确实学会（+4pt）但 RGBT 域指标零移动——**跨域数据教会的是跨域题型** |
| 第三轮 | 按误差解剖定向构造 29,583 行：抗"视觉显著性塌缩"硬负例 3,445（同图有行人动物干扰、查询目标为无生命物、干扰框必须在候选内）+ 序数行 8,673 + 部件行 2,791 + 常规 + 10% 旧数据回放 | λ 从 0.3 到 1.0 单调上升，λ1.0 = 0.7598（全项目本地最高） | λ1.0 → 0.6898；λ0.5 → 0.7112 | 本地增益官方不兑现 |

**根因分析（按证据强度排序）：**

1. **本地验证集与官方题型的结构性错位（核心根因）。** 我们的冻结验证集（2032 行，自建、带标注、用于一切本地对比）中**序数类查询为 0 条**，而官方约 30% 是序数题；验证集同样没有深度类查询（官方约 9%）。这 39% 的官方分值维度在本地**完全不可测量**。微观证据：第一轮微调的人工解剖（152 例错误样本）发现模型向"视觉显著物"（行人、动物）塌缩——这恰是序数题（"从左数第二个"需要克制显著性、按约束数数）最怕的失败模式；三轮训练中序数专项评测从未移动过（始终 ≈0.09）。
2. **官方对适配器强度的惩罚曲线陡峭且从半强度就开咬。** 三点实测（纯微调配方）：λ0.3 官方偏移 +1.1pt；λ0.5 偏移 −1.4pt；λ1.0 偏移 −7.0pt。本地验证分随 λ 单调上升（0.6964→0.7249→0.7598），与官方**反向**——两条曲线的剪刀差正是序数盲区（第 1 条）的宏观表现：适配器强度放大训练先验，先验贴合本地题型 → 本地涨；官方序数/复合题不贴合 → 放大错配。
3. **训练增益的官方兑现率随适配器复杂度恶化。** 第一轮简单适配器：本地 +1.53pt → 官方 +0.74pt（兑现 48%）；第三轮定向适配器：本地 +2.85pt → 官方 +0.38pt（兑现 13%）。定向数据越"贴着本地验证集的病灶"造，本地越涨、官方越不认——**定向的本质是向验证集分布过拟合**。
4. **辅助成分与强适配器的非线性互斥。** 辅助框注入在弱适配器上 +2.5pt（本地），在第三轮适配器 0.5 倍强度上反而 **−11pt**（本地 0.6142）：第 101 个候选的存在本身就扰乱了模型对前 100 个候选的判断（未选中第 101 框的行准确率从 0.71 掉到 0.50）。**组件级验证过的技巧换宿主后必须整体重验，不能因为"它单独是好的"就移植。**

## 五、红外模态方向：信息真实存在，推理期无法收割

**价值测量（oracle 层，答案是肯定的）**：让 WeDetect 检测器改跑红外图像，红外框能覆盖可见光池漏掉的目标——候选池合并后覆盖率上限从 0.8814 升至 0.9045~0.9242（视注入框数），**114 行"池里根本没有正确答案"的题可由红外收回**。

**四种推理期用法全部失败：**

| 用法 | 结果 | 死因 |
|---|---|---|
| ① 红外框注入候选池（每图 +10 框） | 本地 0.7215，与不注入分毫不差；模型 44 次选中红外框仅 22.7% 正确 | **架构性**：选择器以可见光图像为唯一验证依据，红外框指向可见光上看不清的目标，模型"无法验证"故永不信任 |
| ② 暗光图整线切换到红外（检测与看图全换） | 前置分析判死（未跑完） | 红外单独覆盖率 0.8499 低于可见光 0.8814，全切换天花板倒亏 3.2pt |
| ③ 阈值定向切换（只对暗光图换红外） | 前置分析判死 | 可回收的 114 行与图像亮度无关（其亮度中位数与全体几乎相同）、其可见光候选池都是满的 100 框——**没有任何可观测信号能把这 114 行挑出来**，定向无从谈起 |
| ④ 可见光+红外左右拼接成一张宽图给选择器看 | 本地 0.7077（−1.4pt）；模型 34 次选右半区（红外）框仅 14.7% 正确 | 宽图使每个物体分辨率减半（小目标更难认）；模型仍不信任红外半区——"看得见"解决了，"信任"没解决 |

**结论**：红外的信息增益真实（+2.3~4.3pt 覆盖上限），但选择器从未被训练过跨模态验证，一切推理期手段绕不开这一点。正解是**模态感知的选择器训练**（输入含红外/深度），前提是先建成题型对齐的本地评测集（见第八节）——本轮时间不可行，留作下轮首要方向。

## 六、深度模态方向：盲打的教训

**动机**：官方 527 条查询（9.3% 分值）是"离相机最近/最远"类显式深度超问，而毫米级 16bit 深度图是官方提供、全员闲置的权威数据源。

**做法（保守设计）**：对这 527 题，用深度图计算每个候选框的框内平均深度并排序，仅在四个条件全部满足时才改判模型答案——几何极值框与模型所选框完全不同位置、深度差 ≥25%、两框面积比在 0.2~5 倍之间（同类物体表观尺寸代理）、查询不含部件词（头/角/手等，因为候选框是整物级）。最终改判 81 行（全量 1.4%）。

**结果**：官方 0.7077（−1.11pt）。由两包预测仅 81 行不同可精确归因：**至少 72/81 次改判把原本正确的答案改错（破坏率 ≥89%）**。

**根因（按可能性排序）**：
1. **深度图与可见光的对齐从未被验证**——本地验证集源数据只有可见光+红外，深度实验只能盲打，若存在系统性偏移则排序整体失真；
2. 框内平均深度被前景/背景遮挡污染；
3. 模型原本就大多正确：它利用的姿态、上下文线索（"leaning down 的那位"）比框均值深度信息量更大，"与深度均值矛盾"不等于"错了"。

**元教训**：**没有本地验证的干预，保守主义只能控制亏损幅度（−1.1pt 而非 −3pt），不能翻转期望符号。** 这 1.11pt 学费同时预埋了另一个决定：按预注册规则，序数类几何求解（30% 分值池子）取消开工——其机制先验随本实验一起被摧毁。

## 七、候选池扩展方向：覆盖上限是真的，选择器接不住

- **测量**：让检测器输出前 200 名（而非前 100 名），第 101~200 名的框能再覆盖 46 行池盲区（覆盖上限 0.8814 → 0.9040），且是同模态框、不存在红外那样的验证死结。
- **验证**：候选池扩到 150 框后重跑选择，1000 行中期准确率 **0.5110**（对照 0.72），触发预注册杀线处决。
- **死因**：与红外注入的"中性"相反，同模态多出的框全部是"看得见、验证得了"的干扰项，选择器在 ≤100 候选的分布上训练与评估，被同模态候选洪流淹没。
- **结论**：覆盖上限的增益（红外 +2.3~4.3pt、深挖 +2.26pt）与选择器的崩溃同时为真——**欠的是"大池 + 多模态"的训练，不是推理期的池手术**。

## 八、系统性根因总结：一切校准误差源于验证集失真

回看九发提交：除架构更换（#1→#3）外，**每一次"本地说涨"的改动官方都没有兑现**。宏观常数（全部实测）：

| 量 | 数值 |
|---|---|
| 推理配方类增益的官方兑现率 | 46~48%（三次独立复现） |
| 简单微调增益的兑现率 | 48% |
| 定向微调增益的兑现率 | 13% |
| 全强度适配器的官方惩罚 | −4.6 ~ −7.0pt |
| 本地验证集盲区 | 序数 0/2032（官方 ~30%）、深度 0（官方 ~9%） |

**若比赛继续，第一优先级不是任何模型工作，而是**：从官方示例标注数据构造题型配比与官方一致的本地评测集（序数 ~30%、空间 ~27%、深度/热 ~9%、复合题含在内）。这一个动作的校准价值超过其他一切——本轮所有失败都发生在它缺失的阴影里。

## 九、方法论资产（对同类比赛可复用）

1. **分数分解先行**：把任务拆成"覆盖率 × 选择率"，每一步改进都知道自己攻的是哪个因子、上限多少（oracle 测量先行，零成本定天花板）；
2. **预注册发枪线与杀线**：所有"是否上官方/是否继续跑"的阈值在实验前写死，杜绝临场加注（本轮两次杀线处决、两次预注册否决均按此执行）；
3. **冒烟制度**：任何长实验先跑 200~500 行看中期数，方向不对立即处决（本轮一次处决节省约 40 分钟 GPU，另一次前置分析直接免掉两小时）；
4. **对抗性审查清单**：任何脚本/命令执行前逐项过（文件名精确匹配、键匹配预检、编号基、幂等可续跑、启动防重入、坐标解析先人工核对十例、提交包行数与逐行 diff）——本轮拦下两处必崩 bug；
5. **多模型融合铁律**：语义最强者独裁，弱者只供候选/证据；
6. **免费期权式提交**：在"取最高分"规则下，已完成推理的任何候选提交都是零下行风险的彩票，但每张彩票要先过本地这道闸——本地闸门失效时（盲打），保守干预 + 小干预面。

## 十、若进入下一轮的路线建议（按期望排序）

1. **建题型对齐的本地评测集**（第八节）——先校准尺子，再谈提分；
2. **模态感知选择器训练**：输入并入红外（拼接或双流），用 1 的评测集验证序数/深度切片——红外 +2.3~4.3pt 与深挖 +2.26pt 的覆盖增益都在等这个收割器；
3. **候选池升级**：检测器微调提召回、池携带类别标签（解锁序数几何求解）、大池训练；
4. **弃用清单**（全部有定量依据，勿重复付费）：全强度适配器、向验证集分布定向造数、跨宿主移植已验证组件、无本地验证的几何干预、任何形式的模型投票。
